# Rohan Kumar Verma — Portfolio Website

A responsive, static personal portfolio for Rohan Kumar Verma, based on the supplied Software Architect / Engineering Lead resume and the visual direction of the reference portfolio.

## Features

- Responsive one-page portfolio
- Professional introduction and career highlights
- Technical expertise grouped by discipline
- Resume-grounded selected project summaries
- Professional experience timeline and education
- Email, phone, LinkedIn and Stack Overflow links
- Mobile navigation; no build step or runtime dependencies
- Basic SEO and social preview metadata

## Run locally

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `rohan-portfolio`.
2. Push the contents of this folder to the repository's `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will publish the site at `https://<your-github-username>.github.io/rohan-portfolio/` (or the root URL if the repository is named `<your-github-username>.github.io`).

## Before publishing

- Confirm that the phone number, email and profile URLs are current.
- Add a professional headshot if desired (the current design uses an initials monogram).
- Add only project screenshots or links that you are authorized to share publicly.
- Review project descriptions and employer names for any confidentiality restrictions.

## Content integrity

Experience, skills, education and project summaries are based on the resume supplied for this portfolio. No unverified client testimonials, project counts, revenue figures or performance metrics have been added.
